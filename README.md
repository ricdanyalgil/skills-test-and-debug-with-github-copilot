# Test and Debug with GitHub Copilot

_Use GitHub Copilot as a testing and debugging partner, then verify its suggestions with evidence._

## Welcome

- **Who is this for**: Developers who know basic Python and want a more reliable Copilot-assisted workflow.
- **What you'll learn**: How to investigate unfamiliar code, design focused tests, find missing edge cases, diagnose a failure, and critically review AI-assisted changes.
- **What you'll build**: A tested and corrected bill-splitting library that never loses or invents a cent.
- **Prerequisites**:
  - [Getting Started with GitHub Copilot](https://github.com/skills/getting-started-with-github-copilot), or equivalent familiarity with Copilot Chat
  - Basic Python, Git, and terminal experience
  - Access to GitHub Copilot and GitHub Codespaces or VS Code
- **How long**: This exercise takes less than 45 minutes to complete.

In this exercise, you will:

1. Explain unfamiliar code and record a debugging hypothesis.
1. Generate focused tests from explicit behavior requirements.
1. Add edge cases that Copilot did not initially consider.
1. Use a failing test to diagnose, fix, and refactor the implementation.
1. Review the final diff and document how you verified Copilot's suggestions.
